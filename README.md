# Adventure Works Sales Analysis | Power-BI

# Project Overview
An interactive sales analysis project built with Microsoft Power BI to explore sales performance, budgets, customers informations, product trends, and territories performance.

# Dataset Source
The dataset was obtained from Kaggle.

# Tools used
- Microsoft Power BI
- Power Query
- DAX

- # Project Objectives
- Analyze sales performance and trends.
- Identify top-performing products.
- Evaluate customer and regional sales.
- compare actual sales against budget.

# Skills Demonstrated
- Data Cleaning
- Data Modelling
- DAX
- Data Visualization
- Dashboard Development
